## Cara Menjalankan Notebook

Notebook dapat dijalankan melalui Google Colab atau Jupyter Notebook.

Cara menjalankan melalui Google Colab:

1. Upload notebook ke Google Colab.
2. Pilih menu **Runtime**.
3. Klik **Run all**.
4. Pastikan seluruh cell berjalan tanpa error.

Cara menjalankan secara lokal:

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn requests gdown
jupyter notebook
```

## Kesimpulan Umum

Dari Pertemuan 1 sampai Pertemuan 7, saya mempelajari bahwa proses Data Science dilakukan secara bertahap. Tahapan tersebut dimulai dari memahami data, membersihkan data, melakukan analisis statistik, membuat visualisasi, menyiapkan data untuk Machine Learning, hingga membangun model prediksi sederhana.

Hal penting yang saya pelajari adalah kualitas data sangat memengaruhi hasil analisis dan model. Data yang belum dibersihkan dapat menyebabkan hasil analisis kurang akurat. Selain itu, preprocessing seperti encoding, train-test split, dan scaling perlu dilakukan dengan urutan yang benar agar tidak terjadi data leakage.

Repository ini menjadi dokumentasi perjalanan belajar saya dalam memahami dasar-dasar Data Science secara praktik.
